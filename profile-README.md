# Hey, I'm Ryan (NutypeBuddha)

Building tools that make AI actually trustworthy.

## What I Work On

**[CID](https://github.com/nutypebuddha/cid)** — Calibrated Inference Device  
A per-token validation layer for LLMs. Think of it as a firewall between AI output and reality.  
Math validation, logic checking, fact verification, fallacy detection — all in ~630KB of pure Rust.

**[CID Bridge](https://github.com/nutypebuddha/cid-bridge)** — Universal MCP Bridge  
Any AI chatbot (Grok, Claude, GPT, Mistral) hooks into CID validation through one endpoint.

## Tech Stack

- **Rust** — systems programming, WASM targets
- **JavaScript/Node.js** — bridges, APIs, tooling
- **Docker/K8s** — deployment and orchestration
- **Pachinko mechanics** — yes, really (for validation routing)

## Philosophy

LLMs are powerful but unreliable. CID doesn't replace them — it validates them.  
Every math claim gets checked. Every logical argument gets tested. Every fact gets verified.

The goal: AI you can actually trust.
